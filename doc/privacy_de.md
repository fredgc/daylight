# Datenschutzerklärung

Daylight respektiert Ihre Privatsphäre.

## Grundsätze

* **Lokale Verarbeitung**: Die Berechnung der Sonnenzeit erfolgt vollständig
  auf Ihrem Gerät.

* **Keine Serverübertragung**: Standortkoordinaten werden zu keinem Zeitpunkt
  an externe Serverübertragen.

* **Keine Nachverfolgung**: Es werden keine personenbezogenen Daten erfasst.
