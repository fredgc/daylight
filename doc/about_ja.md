# Daylight - 地方太陽時

「まったく、夏時間なんて**大嫌い**だ！時計が飛び飛びになると、*時空連続体*の**連続性**そのものを疑いたくなる！」と心の中で思ったことはありませんか？あるいは同僚に言いましたか？長い**仕事**の一日のあと、**バス**の中で誰かに話しましたか？それなら、このアプリはあなたのためのものです！**休暇**でドライブに出かけたのに、時計が突然1*時間*進んだり戻ったりして**ジャンプ**したことはありませんか？落ち着きませんよね？こうした**恣意的な**タイムゾーンの変更は運転の危険にもなり得ます！そう、このアプリはあなたのためのものです！

Daylight Local Time Zoneアプリは、**あなただけの**地方タイムゾーンで時刻を表示します。**Android**スマートフォンにアプリをインストールするか、**ノートパソコン**でWebページを開いたままにしておけば、現在地に応じて時計が常に連続的にタイムゾーンへ調整されます。もう**不連続**はありません！

「でもフレッド、**冬**にもっと**日光**の時間を増やすために時刻を調整するのはどうなの？」と、まるで私の**左**肩のすぐ後ろに立っているかのように、あなたの声がはっきり聞こえてきます。このアプリはその問題も解決します！地方太陽時では、午前6時が**日の出**、午後6時が**日の入り**になるように時刻が調整されます。一見すると不可能に思えますが、高度な補間アルゴリズムを使って1分あたりの秒数を調整することで、**毎日****正確に**12時間の日照時間になるようにしています。

Daylight Local Timeは**パーソナライズ**されています。最先端の*機械学習テクノロジー*を用いて、あなたの現在地を「学習」するからです。この位置情報は**楕円体**に投影され、**国際的な天体物理学者**によって考案され、**NASA**の全地球測位衛星システムでも使われている数式に入力されます。これらの数式から、日の出と日の入りの**正確な**時刻を計算できます。

**国際化：** このアプリは時計に24時間表記を採用しているため、国際化に対応しています。外国人でない場合、午前中は普通の時刻ですが、午後は時刻から**12を引く**必要があります。

**プライバシー：** このアプリはタイムゾーンをパーソナライズするために位置情報を使用しますが、この位置情報や、性別、体重、身長、歯とタトゥーの比率、年齢といったその他の**個人情報**を*サーバー*や**クラウド**に保存することはありません。仮に保存したとしても、見ずにすぐ削除します。

**アクセシビリティ：** このアプリは時計に大きなフォントを使っているので、**大丈夫**なはずです。

**既知の問題：** このアプリは**地球**の標準的な楕円体モデルを使用しているため、炭鉱の**坑夫**であったり、**大きな**山に登っていたり、飛行機で**飛んで**いたりする場合は、日の出と日の入りが少しずれることがあります。また、地球専用であり、**Android**と**Web**でのみ動作します。iPhoneや*Blackberry*をお持ちの場合、あるいは**冥王星**のような別の惑星に住んでいる場合は、このアプリは動作しません。別の惑星出身でも**地球**を訪れているのであれば動作するはずです。ようこそ！楽しんでください。ただし牛を傷つけないようにお願いします。

**未知の問題：** ベータテスターがいくつか問題を見つけてくれましたが、それをメモした紙をなくしてしまったので、もう既知ではなくなりました。問題を見つけたら教えてください。
