# Politique de confidentialité

Daylight respecte votre vie privée.

## Principes

* **Traitement local** : Le calcul de l'heure solaire est effectué
  exclusivement sur votre appareil.

* **Aucune transmission de position** : Vos coordonnées géographiques ne sont
  jamais transmisesàdes serveurs externes.

* **Aucun suivi** : Aucune donnée d'identification personnelle n'est
  collectée.
