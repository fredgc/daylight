Daylight Local Time Plan

This document outlines the strategic roadmap, mathematical foundations, and milestones for the Daylight Local Time project.

Note: Active day-to-day tasks and issue tracking are managed dynamically using ~/bin/todo.py. Run ~/bin/todo.py list to view active tasks.

1. Astronomical Time Calculation & Physics

  • True Solar Time vs Mean Solar Time: Incorporate the equation of time (orbital eccentricity and axial obliquity) to accurately compute true local solar noon based on geographic longitude.

  • Variable Second Rates: Dynamically calculate local daylight hours between sunrise and sunset, adjusting daylight seconds so 12 daylight hours divide solar daytime proportionally throughout the year.

2. Clock Face & UI Rendering

  • Custom Vector Clock Face: Replace third-party widget dependencies with a custom CustomPainter clock face supporting:

    • Custom dial markers and numerical typography.

    • Distinctive hour, minute, and daylight second hands.

    • Embedded solar position / elevation indicators.

  • Responsive Sizing & Dark Mode: Implement responsive scaling for mobile screens and support dark mode themes.

3. Platform Distribution & Android Package

  • Package Android APK and deploy to Google Play (org.gchouse.daylight).

  • Test GPS permissions and location fallback flows across Android versions.
